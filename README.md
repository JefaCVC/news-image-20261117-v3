The world's news in one image — Tuesday 17 November 2026: 43 stories, 6 continents, one cream-paper broadsheet front page. Three leads, ten pictured secondaries drawn as mini-infographics, a numbers strip, a world map with numbered pins, briefs grouped by region, and a date-check box naming the big stories left out because they happened before Tuesday. A program that writes the day's world news as one 1024×1024 image.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the image to `out/entry.png`. In the grader, `node main.ts` writes it to `/output/entry.png`.
